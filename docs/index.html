卷 首 简 介
Introduction
❖

「桃白簪花」是一份面向 mihomo（Clash Meta）内核的配置覆写脚本： 将机场订阅覆写为一套标准功能名 / 服务名命名的完整策略组体系，并针对 「超稳定、超低延迟访问各个 APP」做了四项增强。

🙏 本项目基于 AIsouler/MyClash 的 mihomoScript.js 微改而来—— 分流逻辑、规则集与节点处理均出自原作者之手。本版在其基础上做了 命名重塑与连接稳定性增强，并重新设计了图标、文档与项目结构。
🌸 桃白簪花 · 主视觉
四 项 增 强
Four Enhancements
❖
壹

🔎sniffer 域名嗅探

TLS / HTTP 域名嗅探，分流更精准；QUIC 被拦截时自动回落 TCP，视频、语音不断流。

贰

🔒TLS 指纹统一

global-client-fingerprint: chrome，降低 CDN 风控拦截概率，连接更稳。

叁

🔗30s 空闲保活

keep-alive-interval 与 tcp-keep-alive-idle 均 30s，NAT 映射不易失效，减少重连与延迟抖动。

肆

🌸「自动选择」组

50ms 容差 url-test 实时测速，始终自动切换最低延迟线路。

此外完整继承原脚本招牌能力：动态地区策略组 · 倍率识别 · 私有 DNS / hosts 修复 · 自定义节点 · 链式代理

Usage
❖
复制脚本直链

在支持「链接覆写 / 远程脚本」的客户端中直接填入下方地址。

或在 Clash Verge Rev 中粘贴

订阅列表 → 右键机场订阅 → 编辑脚本，粘贴 Script/taobai-zanhua.js 全文保存。

关闭客户端 DNS 覆写

设置 → DNS 覆写关闭，交给脚本接管，避免冲突。

重新激活订阅

即可看到全套标准命名策略组。Bettbox 用户可直接图形化开关各项功能。

https://raw.githubusercontent.com/JokerXiaoMo/taobai-zanhua/main/Script/taobai-zanhua.js
⚠ 注意：仅用于机场提供的订阅配置文件进行覆写，勿用于自行编写的配置。
